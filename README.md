# AGRIPHOTOFLEX

Este repositorio est\u00e1 dise\u00f1ado para colaborar en la creaci\u00f3n de scripts relacionados con el uso de **bifacial_radiance** en aplicaciones de **agrivoltaica**. El objetivo principal es facilitar simulaciones y an\u00e1lisis relacionados con sistemas agrivoltaicos.

## Contenido
- `scripts/`: Scripts relacionados con simulaciones y an\u00e1lisis.
- `datos/`: Datos utilizados o generados por los scripts.
- `ejemplos/`: Ejemplos pr\u00e1cticos de uso.

## Requisitos
Para utilizar los scripts de este repositorio, aseg\u00farate de tener instaladas las dependencias indicadas en el archivo `requirements.txt`.

## Instalaci\u00f3n
Clona este repositorio e instala las dependencias:
```bash
git clone https://github.com/Alexmb1985/AGRIPHOTOFLEX.git
cd AGRIPHOTOFLEX
pip install -r requirements.txt
```
